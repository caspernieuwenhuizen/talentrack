# A three-week reference phase profile, and the groundwork for per-team cycles (#3357)

Bump: minor

The VCT configuration screen's reference profiles gain a three-week option
alongside the existing four-week, six-week and five-week speelwijze cycles. It
runs introduce → load → unload: three weeks leaves no room for a peak week, so
it is a different shape rather than a shortened six-week ladder.

Behind it, the schema for per-team repeating cycles — a cycle length and start
week per team, and a place to record a week a coach has set to neutral by hand.
Nothing reads them yet; configuring a cycle arrives with the screen that edits
one. An academy that never sets a cycle up plans exactly as it does today.
