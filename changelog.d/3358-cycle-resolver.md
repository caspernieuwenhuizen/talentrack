# The cycle knows which week a team is in, and pauses for a game (#3358)

The rule behind per-team cycles: a week in which the team plays is neutral, and
that week is not spent. A team in week 3 of its cycle that plays on Saturday
stays in week 3 the following week — the cycle stretches around the fixture list
instead of drifting out of step with it. Games and tournaments both count; a
cancelled game does not.

A coach can also set a week neutral by hand, or force a week to run normally
despite a fixture, for the friendly that was never meant to interrupt anything.

Nothing surfaces this yet — the planner starts using it next, and the screens to
configure and correct a cycle follow.
